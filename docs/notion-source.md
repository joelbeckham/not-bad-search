# Notion sources

In Settings → Sources → Add Notion, enter root page URLs/IDs and/or exact teamspace names/IDs, one per line. New sources start paused, with hourly polling and image indexing enabled. Unpause and save to begin. The source uses the shared Bifrost connection and its existing Notion permissions.

Page roots include structural child pages recursively. Databases enumerate their data-source page URLs directly through notion-query-data-sources using ordered SQL batches and a saved last-URL checkpoint. Each page is fetched as Notion-flavored Markdown, with images downloaded separately. Ordinary links and page mentions do not expand the scope. Teamspaces discover all accessible pages, including their descendants. Duplicate pages within one source are indexed once. Each successful traversal step is checkpointed; cancellation, retries and restarts do not lose the queue. Deleted or inaccessible pages retain their last indexed copy until the source is removed.

Notion's deployed search tool has a 50-result cap and no pagination cursor. Teamspace discovery splits creation-date windows to stay below that cap. If a one-day window still hits the cap, the source reports an incomplete import and retains its checkpoint. Use narrower page roots or a connector exposing paginated discovery; this build cannot guarantee complete imports of those dense teamspace scopes. Database imports do not use capped search. Unsupported Notion folders and truncated page responses also report errors instead of silently dropping descendants.

Uploaded images are downloaded immediately using the short-lived URLs returned by fetch. Signed URLs are not persisted. Public HTTPS images are also supported; redirects and private-network URLs are not followed. Supported formats are PNG, JPEG and WebP up to 10 MiB, subject to the existing image dimension limits. Image failures remain visible in sync status. Cached images enter the existing Processing pipeline for searchable text and descriptions; configure its model and credentials there. Image results link back to their Notion page. Pages use local previews and Open in Notion links; date sorting uses the page's last-edited timestamp when supplied.

Checks: `cargo test --test notion`. `bifrost-check notion-smoke <new-directory> <page-id>` runs one traversal batch with real image downloads into an isolated index and queues images without calling the image model.
